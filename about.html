About Himanshu Pandey

I help businesses, ecommerce teams, and web agencies identify and fix website accessibility barriers through manual WCAG 2.2 testing and practical, code-level remediation—without sacrificing visual design or site performance.

With 50+ websites delivered, 200+ accessibility issues fixed, and 48 completed Upwork jobs backed by 5-star client feedback, my focus is simple: bridge the gap between complex WCAG standards and real-world frontend code.

My Testing & Remediation Methodology

Automated scanners only catch a fraction of accessibility issues. My workflow combines developer-level code inspection with real assistive technology testing:

Manual Keyboard Testing

Testing every menu, dropdown, modal, form, and checkout step using only Tab, Shift+Tab, Enter, Space, Escape, and Arrow keys to eliminate keyboard traps and missing focus indicators.

Screen Reader Verification

Evaluating real user experience with NVDA, JAWS, and VoiceOver to ensure headings, landmarks, form labels, dynamic alerts, and ARIA states announce clearly.

Code-Level Fixes Over Overlays

I never recommend overlay widgets as a substitute for accessible HTML, CSS, JavaScript, and ARIA. Fixes are applied directly at the source level and retested for verification.

Plain-English Reporting

Audit findings are written with severity priorities, annotated screenshots, user impact notes, and copy-ready code examples so developers can act immediately.
